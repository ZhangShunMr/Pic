# 车外行人警示声音传播与覆盖设计软件 V1.0

在同一项目中编辑警示扬声器、参考频谱、背景和观察点，比较自由声场近似下的声级、工程目标覆盖、方案快照与相对试听。新项目独立于仓库原有软件，**入口为 AvasCoverage.sln，启动项目为 Avas.App**。C# / .NET 10 / Blazor Interactive Server，采用MVVM，无第三方NuGet生产依赖。

## 运行

安装.NET SDK **10.0.403**或同版本带后续补丁，并使用现代浏览器。

```sh
dotnet build AvasCoverage.sln
dotnet run --project src/Avas.App
```

打开 `http://127.0.0.1:8786`。也可使用 `./run.sh` 或 `run.bat`。指定端口及可写数据目录：

```sh
dotnet run --project src/Avas.App -- --port 8787 --data-directory /your/writable/avas-data
```

Windows可在支持.NET10的Visual Studio中打开.sln，将Avas.App设为启动项目；本次只在Linux中实际构建运行，Windows及Visual Studio按F5未验证。浏览器为C#本机应用的界面宿主，服务只绑定回环地址。

## 实际流程

1. 普通启动为空白。在项目页填写名称、责任人、车辆、目的并应用；模拟示例通过独立按钮载入。
2. 添加最多8个扬声器，分别输入位置、高度、朝向、轴向参考距离、七频带声压级、频响修正、增益与来源。指向指数0定义全向；其余采用水平余弦幂近似。
3. 输入背景频谱与来源，定义接收平面、网格范围和步长、车辆轮廓及工程阈值。频谱CSV先预检再整体替换。
4. 添加观察点、生成环形点集或批量CSV追加/替换；坐标编辑和图形预览配合使用，当前版本不提供拖拽。
5. 运行计算，核对色图、工程覆盖、观察点数值、七带频谱、传播与源贡献，以及输入复核提示。修改输入使结果过期。
6. 保存独立快照比较方案；条件不一致拒绝差值。参数扫描试算朝向、增益或位置，确认后才应用取值；方向剖面按距离检查离散点值。
7. 可内嵌PCM16 WAV分析数字频谱；不自动改变物理声级。由相对谱和人工参考生成的输入标为估算。观察点试听使用导入声音或固定种子噪声，支持背景、统一数字参考、峰值拒绝与WAV下载。
8. 保存到本机项目库，重复保存保留.bak；下载.avasproj可搬迁后上传重开。成果可导出自包含HTML、网格/点CSV、SVG、计算JSON、比较/扫描/剖面CSV。下载生成后需点击底部链接，浏览器决定落盘路径。

字段编辑、应用、保存和结果状态分别显示；涉及依赖操作时拒绝未应用草稿。新建/打开/示例替换与删除有确认；刷新、关闭或会话丢失仍可能丢失未保存内容。项目内嵌频带、原始WAV、快照和累计审计，不依赖原始导入路径；保存检测外部文件冲突，支持10步撤销重做。项目格式1要求完整字段，拒绝未知版本、损坏对象及音频哈希不一致，未做旧软件格式迁移。

## 计算边界

每带以轴向参考声压级为基准：`L = Lref + correction + gain - 20log10(max(r,rmin)/r0) + 20log10(D)`；`D = floor + (1-floor)*max(0,cosθ)^n`，n=0时D=1。r含高度差；多源逐带按非相干能量和叠加。七带中心为125至8000Hz；A计权只用于七带合成，系中心频率工程近似，不能声称为全频积分。

工程覆盖要求当前指标达到用户声级阈值且信号背景差达到目标；覆盖率为有效网格节点比例，不是人群可听率或精确面积。默认45dB/3dB为工程示例。车辆轮廓仅示意和排除内部网格，未模拟遮挡、反射、衍射、地面、气象、相干干涉或真实三维车身。截断值不具有近场解意义。不做法规符合性或实际可听性判定。

数字音频以幅值1为dBFS RMS参考，不等同声压。试听是24kHz单声道、七带整形、50ms淡入淡出的相对示意，未校准设备、不模拟到达时延和双耳效果；瞬态混合与非相干声级模型不等价。短记录补静音，缺能量频带不能凭空补充，重采样和有限FFT不具备专业音频工作站精度保证。实际人耳听辨及实车效果未验证。
