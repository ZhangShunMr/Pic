# 模型与参数说明

本软件是点源自由场布置估算，模型标识free-field-incoherent-1，不是法规计算器。所有图、指标和导出均须结合来源标记及以下口径使用。

|指标/方法|目的与输入|公式或步骤|默认与范围|异常和验证|限制|
|---|---|---|---|---|---|
|几何传播|将轴向参考声压级换算至接收点；米、dB re20µPa|三维距离r，−20log10(max(r,rmin)/r0)|r0=1m，范围0.1–10；rmin=0.5m，范围0.1–10|源1m60dB，接收2m同高→53.979400dB；零距离截断并标记|不含车身、地面、气象；截断不是近场解|
|水平指向性|位置、朝向、n、floor|D=floor+(1−floor)max(0,cosθ)^n，20log10D；n=0定义全向|n=1，范围0–8；floor=.2，范围.01–1；朝向−360–360°|前向0dB；后向floor=.2→−13.9794dB|频率无关的水平经验模型，不对应已验证扬声器|
|参考谱与修正|七带轴向声压级、频响修正、增益|逐带相加后加传播修正|新源各带60dB，范围−60–140；修正/增益0，范围−40–40|完整七带、唯一频率，缺失和非有限拒绝；零dB有效|默认纯工程输入，应核对来源与重复频响|
|多源叠加|各启用源接收频带声级|10log10Σ10^(L/10)|最多8源，停用源不计|双同强源增加3.010300dB；无启用源拒绝|非相干，不计算相位干涉|
|七带合成|七频带能量；可选A计权|逐带加A修正后能量和；频带模式不加A|125…8000Hz；修正−16.1,−8.6,−3.2,0,1.2,1,−1.1dB|七带60dB→68.450980dB（非计权）|有限带与中心修正，非全频积分或标准滤波器|
|背景与合成|空间均匀背景七带|背景以同指标合成；总声级=信号与背景能量和；背景差=信号−背景|各带35dB，范围−60–140|独立公式核对；背景来源保留|背景空间均匀，不从录音自动标定|
|工程覆盖|声级阈值与背景差阈值|同时满足两目标；节点比例×100%|45dB与3dB；范围−60–140、−40–60|边界>=含相等；仅有效网格节点|阈值为工程示例，不是法规或听觉阈值；不作连续面积积分|
|网格与平均|X/Y范围、步长、内部排除|等间距节点；轮廓内可排除；均值为等权能量平均|X±10、Y±8m，step=.5m；最多20000节点|范围/步长无效拒绝；全部排除拒绝|不整除不追加终边界，色块边缘为示意|
|方案比较|两独立快照|同设置、点标识/坐标与源来源类别，否则阻断；目标减基线|最多20快照|同输入增益+3→点差+3dB；不同背景或重建点阻断|条件一致不保证因果或实际效果|
|扫描与剖面|单源参数或方向几何采样|克隆试算，不改变原项目；剖面沿线点值|扫描最多25取值；剖面最多501点|超范围整批失败；剖面解析核对|非自动最优推荐，最远满足点不代表连续半径|
|数字频谱|PCM16单/双声道WAV|双声道取均值；4096点矩形窗FFT分带能量；dBFS RMS|16–96kHz、30s、10MiB；显示下限−160dBFS|1kHz正弦主带、RMS、静音、损坏WAV核对|有限记录泄漏，低采样率高带不完整；不等同声压|
|相对谱人工映射|数字七带比例+人工七带合成参考|Li=L人工+Li数字−L数字合成；越界拒绝|参考70dB，范围0–120|低能量与超范围拒绝；输出估算来源|无标定链路，不自动截断或补底噪|
|相对试听|源音频/模拟噪声，点传播，数字播放参考|整段FFT七带整形；背景叠加；PCM16单声道；50ms淡入淡出|长度3s，范围1–8；数字参考100dB，范围60–140；24kHz|峰值>.98拒绝并提示提高参考；WAV往返和浏览器解码|缺能量带不补充；不保留时延/双耳；瞬态相位混合与非相干模型不同|

所有工程默认值由本项目为可操作的初始流程选定，没有实车标定或标准限值含义。模拟示例频谱见Demonstration.cs固定数列，非测量数据。人工录音分析不得自动转标为实测。源位置、高度、指向性及参考条件需独立核对。

物理关系参考：FHWA《Noise Measurement Handbook》对球面发散给出20log距离比及点源距离加倍约降6dB的关系（https://www.fhwa.dot.gov/Environment/noise/measurement/handbook.cfm）；OSHA Technical Manual噪声章节介绍分频带A计权再能量合成的工程方法（https://obis.osha.gov/dts/osta/otm/new_noise/）。本项目采用上述基本物理关系，不实现这些文档的完整测量、职业评价或认证程序。精细A修正为本软件按中心频率取一位小数的工程常数，未作IEC滤波器符合性验证。
