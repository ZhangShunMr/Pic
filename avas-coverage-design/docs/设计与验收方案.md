# 车外行人警示声音传播与覆盖设计软件 V1.0 设计方案

基线：origin/codex/cloud-dev-20261102，提交 8abe750。仅新增 avas-coverage-design 目录，保留其他软件与原始附件。

目标用户为附件声学及整车NVH工程师。用户在扬声器布置前期，需要在相同接收平面与背景条件下比较位置、朝向和频带输入，识别工程声级目标覆盖不足的区域，输出供样车试验核对的方案；不能用自由声场计算代替车辆实测或法规认证。

核心对象为项目、扬声器、频带表、观察点、计算设置、方案快照、扫描任务及审计事件。七个倍频程中心频率为125、250、500、1000、2000、4000、8000 Hz。频带输入为参考距离、轴向自由场的声压级，单位dB re 20 µPa；频响修正与增益另加。来源文字与类别必须随项目、计算和导出保留。WAV为数字音频，不自动建立声压标定关系。

完整流程：空白建立项目→填写责任人与来源→建立声源与观察点→录入或CSV导入七频带→设置背景、接收平面与阈值→计算并检查网格/点/频谱→保存快照比较或扫描→生成相对试听→保存下载并上传重开→导出CSV、SVG、HTML与WAV。项目内嵌音频和快照，不依赖原始路径。加载替换和删除有明确确认，修改使结果过期，禁止过期导出。

采用C#/.NET 10和Blazor Interactive Server；MVVM：Core实体与计算/IO/音频服务，App可观察视图模型，Razor视图。无第三方运行依赖，仅本机回环服务。新项目手写生产源码基线0，最低3500非空行；统计src下.cs/.razor/.css/.js，排除bin/obj及测试、文档、工具和生成文件，统计清单与哈希随交付保留。各模块均需从界面可进入。

核心方法：球面几何扩散 -20log10(r/r0)；水平指向性幅值为 floor+(1-floor)*max(0,cosθ)^n，再取20log10；源间能量叠加，不计算相干干涉；各频带非计权合成与A计权合成单独显示；工程覆盖按选定频带或合成声级、阈值及信号背景差共同判断。近源距离下限显式截断并标注；车辆轮廓只排除内部网格，不模拟遮挡、反射、衍射、地面或气象。默认阈值为工程示例，无标准含义。

正常独立核对：全向单源1m 60dB、同高2m为53.9794dB；双同强非相干源增加3.0103dB；全频七带60dB合成为68.4510dB。验证空源、缺频带、零级、非有限、超范围、重复ID、损坏项目/CSV/WAV、不同条件比较阻断、保存搬迁重开及结果失效。真实浏览器走完整工作流并截图。
