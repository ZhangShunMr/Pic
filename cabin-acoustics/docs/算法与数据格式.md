# 算法、输入与文件约定

## 理想模型

| 指标/方法 | 目的、公式与口径 | 输入/边界 | 验证/限制 |
| --- | --- | --- | --- |
| 固有频率 | fn=c/2√[(nx/Lx)²+(ny/Ly)²+(nz/Lz)²] | 非负整数阶次，排除000，fn≤截断 | 3.4m纵向首阶50.441176Hz；只适用矩形刚壁 |
| 振型 | phi=cos(nxπx/Lx)cos(nyπy/Ly)cos(nzπz/Lz) | 米制坐标，0≤坐标≤轴长 | 轴向中点节点、壁面法向导数零 |
| 相干源耦合 | S=Σ启用源 A exp(iθ)phi(rs) | 幅值无量纲0—10，相位−180°—180° | 同点反相抵消；不等同声功率或体积速度 |
| 单模态响应 | Hn=(2^d/V)phi(r)S×100²/(fn²−f²+i2ζfnf) | d为非零阶次个数；1m³参考体积；统一阻尼 | 共振幅值反比阻尼；固定研究标度非Pa |
| 总响应 | H=ΣHn，保留复数相位 | 截断非零阶集合、正频带 | 贡献幅值不可直接相加；缺000压缩模态 |
| 相对dB | 20log10(|H|/reference)，下限−120dB | 所有耳点全频带最大幅值共用reference | 非20µPa参考、非dB SPL；零参考也显示−120 |
| 采样RMS | √mean(|H(fi)|²) | 离散频率样点，含补入终点 | 非时间域声压有效值；不同采样不可混比 |
| 采样峰值 | max样点|H|，对应频率 | 频率步长0.25—10Hz | 可能漏掉窄峰，提示步长大于ζfn |
| 剖面 | 48×24中心网格；响应除该剖面max；振型[-1,1] | XY/XZ/YZ，固定轴比例0—1 | 各图局部归一化，颜色不可直接跨图比较 |
| 基准比值 | 20log10(当前峰值/基准峰值)、RMS同理 | 同频带/步长/截断/来源/模拟标记；按耳点Id | 近零基准跳过；多条件变化显著提示 |
| 扫描 | 端点包含的2—21均匀候选，各自克隆输入 | 几何/首源坐标/阻尼；绝对点位保持 | 越界逐行失败；仅目标耳点排序，不是实车最优 |
| 退化标记 | 频率差≤max(1e−8,fn×1e−8)Hz归组 | 保留各阶次基底 | 同频模态基底不唯一，不合并响应 |
| 耦合观察 | 源<幅值和×1%或phi绝对值<0.01 | 分析频带内模态 | 解释性阈值，不是工程合格标准 |
| 截断敏感性 | 截断增加100Hz，最高1000，比较RMS | 其他参数不变；不应用到项目 | 只比较两个截断，不证明收敛 |

声速343m/s、阻尼0.03及尺寸3.4×1.6×1.2m都是软件起始/示例输入，不以法规或实车标定为依据。允许范围见Validation.cs。单次频率样点最多2001，模态估计≤6000，枚举硬上限10000，主要频响约3000万模态项计算预算。取消在频响样点、扫描候选及阶段边界检查，不能声称每个短步骤均可即时中断。

## 项目格式

扩展名`.cabin.json`，UTF-8 JSON，schema=1，最大2MiB。根对象记录项目Guid、名称、修订、负责人、来源、模拟标记、创建和修改UTC时间、备注、模型、声源、耳点、基准、复核、历史。模型字段length/width/height/soundSpeed/damping/minimumFrequency/maximumFrequency/frequencyStep/cutoff；坐标字段x/y/z。内嵌全部数据，无外部引用。

未知字段拒绝；必需对象/数值/点位字段缺少、null、损坏JSON、重复对象键、不支持版本或越界数据拒绝。Owner、Notes等非核心文本缺失可取默认空值；核心模型不静默补默认。旧版格式版本1项目兼容，旧版Web结果及浏览器截图不带入。保存时先Encode+Decode核验，再同目录临时写入和替换，保存后重开；未完成写入不覆盖已有有效项目。项目不保存数值结果，打开后复算。

基准最多12个；点位8个源/12个耳点；复核最多100条；历史最多500条。来源和模拟标记可明确区分演示与人工输入，但没有真实采集链路，不把人工输入“非演示”解释为已校准。

## CSV与报告

点位交换表头为`kind,name,x_m,y_m,z_m,amplitude,phase_deg,note`。source行需幅值与相位；seat行忽略该两列。UTF-8，英文逗号与小数点；引用支持逗号、双引号转义，不支持单元格换行。名称、备注在项目中也禁止换行，以维持点位交换一致。最大100000字符，文件读取最大400000字节。全部行预检成功后替换，不静默跳过错误。

CSV不保留Id及启停，导入生成新Id且全部源启用，note停用提示不会自动恢复启停，需用户核对。完整往返用项目文件。结果CSV以#注释记录软件/项目/来源/模拟/条件，正文数值InvariantCulture，字段CSV引用；失败扫描指标为空，不用0冒充有效量。TXT报告保留公式、来源、单位和限制。PNG仅是当前WPF研究画布，不是实测影像。
