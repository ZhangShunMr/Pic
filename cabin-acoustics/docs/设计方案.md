# 车内低频声学模态与座位声压分布设计软件 V1.0 设计方案

本项目供汽车NVH工程师在低频问题早期研究时使用。将不规则座舱近似为刚性矩形腔，帮助识别低阶声学模态、理解源和座位耦合、安排实测测点。输入为米制尺寸、声速、无量纲模态阻尼比、点声源位置与相对幅值、座位耳点和扫描频带。输出为模态频率、归一化振型、带相位的截断模态叠加响应、统一参考的相对dB和方案差值。软件不提供实车绝对声压、吸声材料预测或安全结论。

基线为新项目0行。最低目标为3500行手写生产源码非空行，统计src下cs、razor、css、js，排除bin、obj、生成、依赖和测试。代码量对应空间场、模态、频响、贡献、方案快照、参数扫描、点位CSV、项目持久化与报告功能。使用C# .NET 10、Blazor Server及MVVM，提供CabinAcoustics.sln；不依赖外部前端服务。

工作流：空白建立项目→填写模型→添加耳点/声源→计算→点选模态或频率→观察剖面/曲线/贡献→保存基准→调整尺寸或声源→比较/扫描→保存重开→导出。独立示例显式标注模拟。所有分析位于一张连续场景页；场景浮层负责几何编辑，下方谱图和结果表保持联动。项目与成果采用侧边文件抽屉，避免顶部模块导航及此前树形工作台。

数据模型包括版本化项目、模型、声源、耳点、基准快照、扫描规则、复核记录。坐标原点为前左下，x向后、y向右、z向上。矩形腔尺寸0.5–10 m、声速300–380 m/s、频带5–500 Hz，最高纳入模态频率100–1000 Hz；阻尼0.002–0.2。有限模态叠加不包括000均匀压缩模态，采用固定100Hz参考和模态范数修正，不宣称完整格林函数或声压传递率。

数学来源：NASA CR-145110（1977）矩形刚性腔模态；Calafà等矩形房间格林函数模态展开（https://arxiv.org/html/2602.09594v2）；Meissner（2020）低频稳态场阻尼研究（https://pmc.ncbi.nlm.nih.gov/articles/PMC7481690/）。软件采用明确披露的无量纲筛查指标，验证解析轴向频率、积分范数、源/测点节点、退化模态保留、阻尼有限性、复数叠加与共同比较参考。

资源风险：本环境验证Linux Chromium和.NET 10；Windows启动脚本与Word实际分页须按可执行条件记录。当前未提供指定申报模板，参考仓库已有手册基本A4版式，申请人/权属/日期待核实。验收包括确定性数值、浏览器真实交互、项目文件重开、损坏文件、CSV预检、报告核对、窄屏和发布搬迁。
