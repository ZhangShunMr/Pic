# 原生桌面重做方案

软件：车内低频声学模态与座位声压分布设计软件 V1.0（Windows 原生重做）。
用户为开展座舱低频方案研究的声学工程师。输入为人工定义的理想矩形腔尺寸、声速、等效阻尼、相干点声源及座位耳点；输出为固有频率、振型剖面、复数相对频响、座位比较、基准差异和参数扫描。

本次为运行平台替换和完整原生交互重做，不以扩充旧版功能规模为目标。旧版手写生产非空行为3608行（CS/Razor/CSS/JS）。新版统计范围为实际参与构建的 src 下手写 .cs 和 .xaml，最低3500非空行；不计测试、文档、生成输出或项目配置。保留适用的核心数学，移除全部 Web 服务、Razor、JS、CSS。不使用代码堆叠或重复视图凑行数。最终清单由工具按该口径输出。

界面采用工程树+声场画布+可调整宽度的属性检查器，左树定位工作区。文件菜单只承担文档操作，不以顶部按钮切换模块。工作区包括模型输入、剖面、频响、模态、贡献、基准、扫描、数值复核及工程复核。使用原生 Menu、TreeView、DataGrid、Slider、Dialog 和自绘 WPF 控件。普通启动无结果，独立示例需显式载入。

项目文件内嵌模型、点位、基准、复核及历史；格式版本1，与旧版兼容，损坏及未知字段拒绝。文件对话框选择位置，写入同目录临时文件后原子替换，保存后解码校验。输入改变立即失效结果；只有有效且一致的快照允许结果导出。导出CSV、文本研究报告和画布PNG，均附模拟标记与适用边界。

计算仍使用刚性矩形腔余弦基底、非零阶模态、100Hz固定标度、1m³参考体积和复数相干叠加。000模态不纳入，不输出Pa或dB SPL。变化源相位保持复数；座位曲线参考同一全频带最大幅值。剖面响应按剖面最大值归一化，振型取有符号[-1,1]。扫描固定绝对坐标，越界行报错。

验收先核对解析解、节点、对称、共振阻尼、相干抵消、缩放、频率网格、数据边界、保存重开、CSV和比较；再交叉编译WPF。Linux无法实际运行WPF，真实Windows界面检查、截图和Word分页为显式遗留，不能用浏览器或模拟图替代。
