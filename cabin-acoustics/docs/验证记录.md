## 可复现命令

1. `dotnet build CabinAcoustics.sln`
2. `dotnet run --project tests/Cabin.Verification -- docs/numerical-evidence.json examples`
3. 用`run.sh`启动本机端口8786后执行`python tools/browser_verify.py`及`python tools/boundary_verify.py`。本次UI测试使用独立的/tmp/cabin-browser-data，不操作用户项目。
4. `dotnet publish src/Cabin.App/Cabin.App.csproj -c Release -o publish`，再运行`python tools/package_release.py`，最后`python tools/release_verify.py`。发布脚本默认使用PATH上的dotnet，本次环境使用CABIN_DOTNET指定安装位置。
5. `python tools/source_inventory.py`、`python tools/build_materials.py`和`python tools/verify_materials.py`。文档验证需要LibreOffice soffice、Chromium和Python依赖。
