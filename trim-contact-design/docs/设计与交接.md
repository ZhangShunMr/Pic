# V2.0 设计与交接

产品：汽车内饰卡扣与防异响接触设计软件，版本V2.0，项目schema1，方法RigidContact-1.0。主工程TrimContact.sln，启动项目TrimContact.Desktop。软件已替换为C# WPF原生桌面实现，生产不含Razor、浏览器宿主、ASP.NET服务或WebView；报告HTML是成果格式。

目标和输入/处理/输出详见重做方案及算法与参数。数据来自用户录入、布置CSV或内置模拟；来源标签持续保存，不推导真实声压。旧版的独立C#力学内核经复用和重新验证，新增桌面ViewModel编排、原生文件操作及输入状态保护。主要计算规则未改名为已验证的真实NVH模型。

## 分层与调用

- Core/Domain：项目、饰板、点位、载荷、任务、几何与严格校验。
- Core/Analysis：刚性法向平衡、库仑限幅切向、包络、扫描、比较、质量与独立平衡核查。
- Core/IO：严格版本化JSON、原生任意路径文件、本机项目库、CSV事务、结果输出。
- Core/Operations：会话事务、20步撤销/重做、方案复制、任务引用、批量预览与过期检查。
- Desktop/ViewModels：全部用户命令、草稿/应用/保存状态、可取消后台计算、结果哈希与预览保护、交互接口。
- Desktop/Views与Controls：原生XAML编辑器、布局图、名义相位曲线，代码后置只负责视图输入提交、验证错误转发和窗口生命周期。

草稿是工作副本的独立克隆。编辑中允许轮廓和支点暂时不完整；应用按草稿校验，计算再按计算条件校验。失败不更改已应用工作副本。数值转换错误阻止保存/计算，业务范围错误指出路径。结果有效性同时要求没有待应用输入、没有转换错误，且报告输入SHA256匹配。任务文字、项目身份不属于力学哈希；方案及载荷名称纳入哈希便于结果追溯。

扫描副本缩减至目标方案并移除非力学验证任务，避免其他方案任务引用阻断计算；原项目任务保留。批量与CSV都绑定原输入、请求和目标方案，变化后必须重新预览。删除点位解除任务引用并保留任务。用户标记完成需有证据文字。

## 文件约定

.trimproj为UTF-8 JSON，最大2MB，schema1，全部必需字段完整。未知schema、缺字段、重复字段/ID、无效引用、非有限数值和损坏结构整体拒绝。内嵌模型可独立搬迁；外部证据只是文字编号，应另行保存原始文件。项目不内嵌计算结果，重开重算。

任意路径文件保存和本机库都用临时文件替换，覆盖前保留.bak，用SHA256检测打开后的外部变化。这个检测针对应用保存前快照，不是跨进程文件锁；不要同时用多个程序保存同一文件。Windows原生另存对话框负责已有目标确认。本机项目库按GUID命名；无已打开库文件的哈希不能覆盖同ID条目，备份恢复复制成新ID。

CSV布置字段和单位见模板；结果CSV在表头包含来源/哈希。分析JSON包含项目、方法、报告及边界。扫描CSV记录实际执行对象/参数和基准输入。HTML报告对用户文本编码，不加载外部资源。导出不自动写入外部证据附件。
