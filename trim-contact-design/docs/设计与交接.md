# 汽车内饰卡扣与防异响接触设计软件 V1.0

## 立项与开发前约定
2026-11-04；基线 origin/codex/cloud-dev-20261102，提交 8abe75017a382f03da0bac6499425725b1a5858d。独立目录 trim-contact-design，未修改已有软件。
面向内饰结构和NVH工程师，在概念布置和样件整改中比较卡扣、毛毡和缓冲块的接触状态，整理公差敏感项与样件验证计划。输入为用户填写的几何、等效弹簧参数、质量和准静态惯性载荷；首版内置样例全部为模拟。
对象关系：项目包含饰板轮廓和质量条件、多个设计方案、共用载荷、来源声明、计算设置与验证任务；方案包含双向卡扣与单边接触点。计算为显式操作，结果绑定输入SHA256，编辑后失效。项目文件内嵌全部输入，不依赖外部数据。
首版范围：轮廓编辑，点位布置，卡扣和接触参数，载荷编辑，名义及所有接触间隙公差角点，周期相位扫描，逐点状态和力曲线，兼容条件方案比较，参数扫描，验证任务生成，撤销重做，项目库、备份、复制、归档、搬迁与JSON/CSV/HTML输出。后续可扩展有限元柔性体和实测导入，本版没有这些能力。

## 核心算法与单位
饰板是刚性平面，法向自由度 q=[z,edgeX,edgeY]，单位mm；点b=[1,(x-CGx)/L,(y-CGy)/L]，w=b·q，L为包围盒最大尺寸。卡扣法向为双向线性弹簧，反力 k*w。接触点压缩 c=max(0,p-g-t+b·q)，p为预紧等效压缩量、g为名义间隙、t为公差偏移。毛毡/缓冲块只作为不同名称的同一种等效弹簧，不内置未标定材料常数。平衡方程 Kclip*q+Σk*c*b=f，f=m*9.80665*an*[1,0,0]（惯性作用在CG）。求解凸分段二次势能，用带回溯线搜索的牛顿法；不收敛或卡扣矩阵近奇异则报错，不生成有效结果。卡扣至少3点且非共线，法向刚度始终大于零。
切向为平面单方向平移，u不含扭转，卡扣双向切向弹簧；已接触点的切向力=min(kt*abs(u),μN)。通过单调二分求总剪力平衡，滑移余量=max(0,abs(u)-μN/kt)。脱离点不承担摩擦。法向和切向为解耦准静态模型，不能模拟粘滑时序、冲击、阻尼、频率响应或真实异响声压。
相位φ等间距覆盖一周期，不重复2π；an=偏置+幅值sinφ，at=偏置+幅值sin(φ+相差)。输入g为加速度倍数，不是位移，频率仅作为工况标签与试验计划，不参与动态放大；扫相位所得是采样包络，非连续极值保证。公差角点枚举每个接触点的±间隙公差，再加名义工况；最多6个接触点即64角点，最多12个卡扣和6载荷，24/48/72相位。公差角点比例不是概率或合格率。
筛查状态基于数值接触阈值1e-7 mm：整周期未接触、接触与分离交替、持续接触；滑移指某采样相位切向弹簧需求超过库仑上限。卡扣过载按用户指定合力限值筛查，限值非行业标准。默认刚度、摩擦和限值均为演示工程初值，真实设计须通过材料与装配试验识别。
