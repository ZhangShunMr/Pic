## 刚性平面法向平衡

`L=max(轮廓宽度,高度)`，点位相对质心归一化基向量 `b=[1, dx/L, dy/L]`。自由度 `q=[z,edgeX,edgeY]` 单位mm；局部位移 `w=b·q`，两个edge/L为小转角近似。法向正方向朝接触支撑。

卡扣反力 `Fclip=kclip*w`；接触压缩 `c=max(0,p−g−t+w)`，接触力 `N=kn*c`。求 `Kclip*q + Σkn*c*b = [m*9.80665*an,0,0]`。这是凸分段二次势能的梯度零点，使用带回溯线搜索的牛顿法。矩阵3×3高斯消元按列选主元；主元低于 `max(1e-12,矩阵最大元*1e-10)` 拒绝近奇异。迭代最多100次，残差阈值 `1e-8*max(1,abs(法向惯性力))`；线搜索α自1逐次减半，充分下降系数1e-4，势能比较容差1e-12，α≤1e-10或未收敛即报错并取消结果。

## 单方向切向平衡

法向先求，再独立求一个平移位移u，无扭转。卡扣切向反力 `kt*u`；接触反力按 `sign(u)*min(kt*abs(u),μN)` 限幅。以卡扣总切向刚度给上界 `abs(Ft)/Σktclip`，在零与上界间单调二分70次，保证全部切向反力之和匹配惯性力。卡扣切向始终有正刚度，因而该问题具有有限上界。

滑移余量 `max(0,abs(u)−μN/kt)`，仅在压缩>1e-7mm时统计，脱离点滑移记0；这不表达冲击或不存在异响。没有摩擦时序记忆与粘滑振荡，不能据此推断声音。

## 指标与用途

| 指标 | 定义、参数与异常 | 解释和限制 |
| --- | --- | --- |
| 接触状态 | 数值接触阈值1e-7mm；全采样压缩≤阈值为全采样脱离，部分≤为存在分离，否则持续接触 | 只描述枚举采样集合，非连续保证 |
| 滑移点数 | 任一采样滑移余量>1e-7mm | 无标准风险权重或总评分 |
| 接触限值比 | 压缩/用户允许压缩量 | >1超用户值，非材料认证 |
| 卡扣限值比 | sqrt(法向力²+切向力²)/用户合力限值 | 卡扣方向与限值来源须另核实 |
| 最大平衡残差 | 所有法向广义残差与切向力差绝对值的最大值 | 广义力矩经L归一化；单位N，另有真实N·mm的名义独立核查 |
| 控制工况 | 记录取得最小压缩、最大滑移或最大限值比的载荷/角点/相位 | 同值按实现遍历规则保留一项，不穷举所有并列 |
| 分离、滑移采样计数 | 枚举条件中满足阈值的样本数 | 比值不是概率、合格率或失效率 |
| 名义相位曲线 | 每载荷仅t=0，折线连接离散点 | 不展示角点曲线，不是动态时间历程 |
| 独立力与力矩核查 | 名义采样逐点ΣN、ΣT与外力之差；质心处ΣNy、−ΣNx | 无切向高度偏心和扭转 |
| 储存弹性能 | Σ0.5*k*w²、Σ0.5*kn*c²，切向以弹性力/kt回推弹性位移 | 单位N·mm，含预紧，不含耗散，不是声学能量 |
| 未平衡干涉 | p−g及p−g±公差 | 尚未求平衡，非实际压缩 |
| 小位移适用性提醒 | 名义位移或edge/L超过几何尺度5% | 工程提醒初值，未标定，不检查全部角点 |

## 比较、扫描与追溯

方案比较只使用同项目同次计算，天然共用饰板、来源、载荷和采样。不同点位数量的计数不能直接排名。扫描在副本上改变一项接触参数，逐值验证并重算，不自动应用或优化。批量修改预览记录完整旧输入和请求状态，应用前两者须一致。CSV预检后项目、目标方案或原文本变化均阻止应用。

结果SHA256覆盖饰板、设置、全部方案与载荷、来源类型与依据；不含任务证据、项目名称和审计时间。未应用编辑时结果视图暂时失效；应用后按计算输入哈希重新判定。任务编辑不要求重算力学。参考文件版本核对按GUID和顶点顺序，不按名称猜测，跨共同条件的结果不做归因。

## 验证依据与边界

正常例：四个对称100N/mm卡扣，1kg、1g、无接触，z=0.024516625mm，各反力2.4516625N；中心100N/mm接触预紧0.2mm、间隙0、零外载，z=−0.04mm，接触压缩0.16mm与16N，四卡扣各−4N。四个50N/mm切向卡扣受10N时u=0.05mm。验证包含符号反转、零载荷、全脱离、零摩擦、摩擦限幅、公差、随机偏心接触平衡与错误输入，详见core-verification.json、desktop-workflow-verification.json。

没有真实车型、材料、卡扣力位移或声压数据，不能验证实车设计效果。刚性平面、小位移与等效刚度假设不适用于板柔性、显著大转角、动态共振、冲击、接触面积演化或材料强非线性。需要独立试验识别参数并判断实际声音。
