# 汽车内饰卡扣与防异响接触设计软件 V1.0

本软件帮助内饰结构和NVH工程师编辑刚性饰板简化轮廓、卡扣与单边接触布置，比较间隙、公差、预紧、刚度和惯性载荷下的接触保持、分离、摩擦滑移及卡扣受力。结果用于确定候选设计与样件验证重点，不预测真实异响声压。

## 构建与启动

安装.NET SDK **10.0.403**，允许同版本带后续补丁。生产无第三方NuGet依赖，使用.NET与ASP.NET Core共享框架。

```sh
dotnet build TrimContact.sln -c Release
dotnet run --project src/TrimContact.App -c Release --no-launch-profile
```

浏览器打开 `http://127.0.0.1:8775`。Linux/macOS也可用 `./run.sh`，Windows可用 `run.bat`。指定端口与数据目录：

```sh
dotnet run --project src/TrimContact.App -c Release --no-launch-profile -- --port 8776 --data-directory /your/writable/directory
```

默认数据目录为应用二进制所在目录下Data。`TrimContact.sln`可用支持.NET10的开发工具打开，将TrimContact.App设为启动项目。Linux命令行和Chromium已实际运行；Windows Visual Studio图形启动尚未验证。界面为Blazor Server本机浏览器宿主，核心、交互逻辑均为C#；不是WPF程序。

发布可用 `dotnet publish src/TrimContact.App -c Release -o ./publish`，进入publish目录后 `dotnet TrimContact.App.dll --port 8776 --data-directory ./Data`。需.NET10 ASP.NET Core Runtime。只监听127.0.0.1，不提供远程访问与身份管理。

## 完整操作

1. 普通启动为空白。填写项目、修订、来源与目标，点击“应用编辑”。内置模拟只能从“载入模拟演示”明确载入。
2. 饰板页建立矩形或顺序输入3至24个顶点，填写质量和质心。轮廓须无自交，点位在轮廓内。
3. 布置页建立方案，至少放3个非共线卡扣；编辑双向法向/切向刚度与合力限值。最多12卡扣、6单边接触点；接触点设置间隙、公差、预紧、刚度、摩擦和允许压缩。
4. 可通过布置CSV整批预检后追加或替换点位；错误整批取消，修改预检输入后需重新预检。模板含模拟参数，不附带标定链。
5. 载荷页定义最多6个共用工况，单位g；相位采样24/48/72，公差为名义加全部正负间隙角点。频率只是标签，不计算动态放大。
6. 计算全部方案，在结果页查看逐点包络、控制工况、名义曲线和原始表；工程复核和平衡核查页辅助核对输入和反力。编辑后旧结果失效，必须重算。
7. 复制方案后独立调整，比较同次同条件结果；扫描单点预紧、间隙、法向刚度或摩擦。批量调整支持平移、刚度缩放、间隙/预紧增量，预览后事务应用。
8. 从结果生成验证任务，记录方法、约定判据、负责人和证据；完成状态由用户声明，不代表软件认证。
9. 保存到本机项目库后实际重开；覆盖留.bak，磁盘外部变化阻止覆盖。下载.trimproj可搬迁，导入同ID不直接覆盖，请先打开磁盘版或复制新项目。归档只读，复制后可继续。
10. 导出自包含HTML、包络CSV、名义逐相位CSV、分析JSON、参数扫描CSV、平衡核查CSV及任务CSV；来源、版本、单位、输入哈希随结果保留。布置CSV是参数交换格式，不包含项目来源；报告含全部设计输入。版本核对页按GUID检查参考项目输入，不改工作副本。

## 计算口径

饰板为刚性平面、小位移。卡扣是双向线性弹簧；接触压缩为 `max(0,预紧量−间隙−公差偏移+局部位移)`。同时求预紧反力与惯性力平衡，再用单方向切向库仑限幅求解。滑移余量是切向位移超出弹性摩擦容许位移的部分；完全脱离点不承担摩擦，滑移记0。

公差角点数和分离/滑移采样比例不是概率、合格率或连续极值保证。默认材料参数、用户限值与5%位移提醒均为工程初值，不是标准。内置示例全部为模拟；“实测（用户声明）”不会自动认证数据。模型不包含板柔性、阻尼、热老化、动态共振、碰撞冲击、摩擦记忆或声学辐射。详见[设计与交接](docs/设计与交接.md)。
