# 算法与数据格式 V2.0

所有转速n单位r/min，f单位Hz，k为每机械转周期数。零速合法；不建模负转向。输入参数和来源为用户提供，软件不认证真实性。

|名称|公式|适用条件与限制|
|---|---|---|
|机械转频|n/60|运动学参考，不证明不平衡|
|同步无刷电气基频|p n/60|永磁无刷同步运行，p为极对数；不是电磁力阶次|
|槽通过参考|Q n/60|转子参考点相对等间距定子槽通过周期，不证明声压峰|
|理想齿槽周期候选|LCM(Q,2p)n/60|等槽、对称永磁、无斜槽，用户确认并填写依据；不含饱和、偏心与制造偏差|
|有刷单刷片通过|K n/60|等宽换向片对单个固定电刷；不乘刷数，不自动生成同步电频|
|自定义机械阶次|k n/60|k=0.001～10000，依据必填；固定载波不能用恒定k替代|

电角与机械角乘极对数的关系参考[MathWorks官方说明](https://www.mathworks.com/help/mcb/ref/mechanicaltoelectricalposition.html)。理想齿槽周期关系参考[Hsiao等，2011，Energies](https://www.mdpi.com/1996-1073/4/12/2166)；只取理想周期，不实施论文有限元和幅值预测。应用边界在候选依据、界面与报告中保留。

扫描以起始值加整数步长计算，总是纳入终值，最多2000个步长（非整步长可另加终点）。观察转速可在范围内且不在网格上。绘图使用解析直线；图外部分裁切，表格完整。

频带交叠解析闭区间为[max(nmin,60flower/k),min(nmax,60fupper/k)]，下限≤上限时保留，支持零宽度带。结果保留各频带来源；相同频率候选不合并。不基于交叠评分，也不称共振诊断。

谱峰规则：内部点A[i]>A[i-1]且A[i]≥A[i+1]，按幅值降序取前N个（默认10，范围1～50）。平台取左缘，端点不找峰，未插值、滤波或prominence筛选。用频谱自己的转速换算候选；|观测−计算|≤绝对容差时全部列出。默认3 Hz，范围0～1000；工程初值不代表标准。无邻近不排除未建模来源，不同频谱幅值不相减。图形超过1000点用各桶极小和极大显示，计算与保存始终用全部原始点。

快照保存当时电机条件与自定义候选副本。按候选稳定标识对应，两边都统一用当前观察转速计算，差值当前−快照。缺项为空，不补零。拓扑不同或转速扫描范围不同显示限制。不存在声级改善或制造优劣结论。

参数扫查：每组1～12个不同整数，无刷枚举p/Q、有刷枚举K，沿用已应用启用状态和假设。反算n=60f/k，区间由max(0,f−容差)与f+容差换算；区间不截取到当前扫描范围，中心另标记是否范围内。会话中保留实际输入条件、旧结果提示和导出防陈旧检查，结果不自动存入项目。

参数边界：p=1～64、Q=1～512、K=2～512；不适用拓扑的档案值仍合法。转速0～100000；终值>起值；步长0.1～100000，区间/步长≤2000；观察值在扫描范围内。频率图上限1～1000000。原始频率0～1000000，幅值有限且绝对值≤1e9，线性单位拒负值，dB可负。

CSV：UTF-8可BOM，表头frequency_hz,amplitude，英文逗号、英文小数点，无引号、千位分隔符、注释或中间空行，尾空行接受。频率严格递增，2～10000点，最大1MiB。必填元数据为名称、转速、单位、参考量/口径、工况和来源。单位为dB、Pa、m/s²、g、A、V或任意单位，不自动校准或换算。SHA-256识别导入UTF-8文本，不证明仪器校准。修改内容或元数据后预检失效；全部错误必须修正后导入，不能只取有效行。

.motorproj：UTF-8 JSON，formatVersion=1，softwareVersion记录创建/最后应用版本。已知格式1旧项目支持读取，字段必须完整；未知、重复或null字段、未知枚举、重复标识、无效隐藏引用、损坏JSON和未来格式拒绝。限制：8MiB、40自定义、30频带、12条频谱/30000总点、12快照/每快照40自定义、2000历史。原始点全部内嵌，无需搬迁外部CSV。

保存本机文件：同目录临时文件写入并Flush后替换，已有目标先备份.bak；通过读取时哈希检测外部修改、移动或删除，发现冲突拒绝。另存到已存在目标需用户确认。新目标若在写入期间被其他程序创建，移动不覆盖。此机制不提供跨进程原子事务或多人并发承诺；用户仍须保留独立备份。从.bak打开恢复为新标识副本。

草稿与状态：档案、电机与复核设置显式应用后重算。保存会验证并应用这些草稿，但新增表单须先完成或重置；导出有草稿时拒绝。每次变更先克隆、验证，成功再替换当前项目，错误保留原有效结果。撤销/重做最多30步且保留历史，重开后撤销栈清空。归档暂停内容变更，允许保存、导出、复制与取消归档。退出保存/放弃/取消只覆盖正常退出，强制终止仍丢失未保存工作。

输出CSV采用UTF-8 BOM、数字InvariantCulture，文字字段引号转义且防公式起始字符；报告HTML和SVG编码用户文字，无远程脚本。SVG含当前候选/频带和图例，不含快照虚线或频谱点，桌面绘图包含这些叠加。原始点CSV只有两列，需配套项目/报告解释来源。输出路径由原生保存对话框选择，消息仅在磁盘写入成功后更新。

无网络业务访问、账户、遥测或云端上传；项目负责人为可选文字，访问与备份由本机文件权限控制。未验证实车效果、最大规模性能、Windows图形运行及多用户使用。
