# 原生桌面重做方案 V2.0

本软件面向汽车附件电机设计与噪声振动复核人员，解决在结构参数、转速、频谱和敏感频带间手工换算易丢失依据的问题。核心对象为项目、电机条件、有依据的候选阶次、频带、内嵌原始频谱、不可变方案快照和操作历史。输入来自人工档案、用户声明的采集数据或明确标识的模拟示例。输出用于安排后续试验与复核，不用于自动认定电磁力、故障或实车改善。

从 main 2bf4fc16fbca9c7ef36c4cce0a7d3034a16a2cd4 建立独立新分支 desktop/accessory-motor-frequency-wpf-20261104。只在本目录增改。备份中的领域计算经完整阅读、保留并重新测试；全部浏览器界面、服务端、端口和下载流程移除，重新编写 C# WPF 原生窗口与 MVVM 应用层。

首版流程：空白启动→新建或独立示例→档案和拓扑草稿→显式应用→候选与频带→CSV预检和导入→谱峰邻近复核→参数枚举/反算→快照比较→本机文件保存重开→CSV、SVG、HTML报告及JSON输出。拓扑不同或范围不同时显示比较限制。所有示例、频带、频谱来源随保存和输出保留。

布局采用深色竖向项目导航、浅色文档工作区和原生数据表、右侧条件检查器；菜单仅提供文件和编辑操作，模块由左侧目录进入。图形使用 WPF DrawingContext 直接绘制，非 WebView。窗口可缩放，工作区有滚动容器和可拖动分隔线。
