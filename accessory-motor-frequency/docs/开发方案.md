# 汽车附件电机电磁激励频率设计软件 V1.0 开发方案

基线：codex/cloud-dev-20261102，8abe75017a382f03da0bac6499425725b1a5858d。仅在 accessory-motor-frequency 新目录开发。无旧代码基线；最低目标为手写生产源码非空行 3600 行（C#、Razor、CSS、必要的浏览器互操作 JS），排除测试、工具、文档、生成物、依赖；其中规则及数据业务用 C#，采用 MVVM。验收另列各语言行数，禁止无效代码凑数。

面向附件电机 NVH 工程师，在座椅、升窗和小型无刷电机场景建立候选频率与转速及结构参数的联系。对象为项目、当前电机方案、候选阶次、结构敏感频段、定转速频谱、方案快照和审计事件。输入来源为人工参数或 UTF-8 CSV；内嵌原始频谱与元数据；计算输出为频率图、交叠转速、谱峰邻近关系、比较差值和可复核报告。候选匹配为筛选线索，不判定根因，不估声压。

技术：.NET 10，C#，Blazor Server，单机回环监听，独立 Core 与 App，ViewModel 负责状态与命令，视图只做绑定和绘图。无生产第三方依赖。以电机剖面对象选择为核心，左侧项目/数据树、中央电机及频率图、右侧条件检查器，下方结果和文件操作连续呈现；无顶部模块切换。采用浅米色图纸、墨绿谱线和赭色选中状态，与旧声学软件的多页导航不同。

首版闭环：空白启动→填写项目→配置拓扑及转速→选择/添加候选→添加敏感频段→导入频谱→检查图表、手算与交叠→快照比较→保存、重开→项目/CSV/SVG/HTML导出。独立示例标明模拟。支持撤销重做、复制项目、重命名/删除数据、项目库、备份恢复、覆盖冲突检查、操作日志。更换拓扑保留但隔离无关参数，候选适用性随拓扑更新。修改立即重算，导出与图一致。

验证：手算 n=1800,p=2,Q=12：转频30、电频60、槽通过360、理想齿槽360 Hz；有刷 K=10 单刷参考通过300 Hz，与全机换向事件不等同。多转速、零转速、非法值、损坏文件、版本错误、重复引用、CSV错误整批拒绝、精确区间求交、比较条件、同频线不合并为因果。真实 Chromium 操作参数、对象、导入、保存重开、备份、下载；保留日志和截图。测试文档与最终实现一致。

风险与边界：电频不等于电磁力，槽通过为运动学参考，理想齿槽候选需要对称等槽永磁拓扑并由用户启用；有刷只提供单刷换向片通过，默认不乘电刷数。实际频谱需给出转速、单位、参考量、来源；不同工况不作幅值比较。大文件及输入上限明确拒绝。无三维电磁场、声学传递或幅值预测。用户模板、Word 实际分页与权属事实若不可得，保留待核实，不声称终稿。

文档交付：运行说明、算法与格式、操作手册 DOCX/预览、信息采集表、真实截图、生产源码清单及排印稿、逐条符合性矩阵和验证记录。申报身份与日期留待申请人填写。
