# Windows实际运行验收（尚未执行）

当前环境Linux，docs/wpf-runtime-attempt.txt记录缺少Microsoft.WindowsDesktop.App的真实启动失败。下列项目不能由Linux构建结果替代。

在Windows 10/11 x64、交互桌面和支持.NET10的SDK环境执行tools/verify-windows.ps1。脚本打开实际WPF窗口，检查空白启动、真实TextBox绑定错误拒绝、独立示例、九个工作页加载和数据表绑定、1100×720截图，并采集实时WPF可视树的PNG。截图不是浏览器或模拟图；未运行时目录中不会存在图片。自动检查通过仍须逐图人工检查。

1. 解压离线发布包，断网后双击MotorFrequency.exe，确认无端口服务、浏览器或额外运行时安装要求。
2. 检查字体、列表选中色、键盘Tab焦点、Ctrl+N/O/S/Z/Y和菜单，分别在100%、125%、150%、200%缩放和最小/最大窗口下查看截断、滚动条与图表。
3. 新建空白项目并按手册完整案例录入；输入NaN、空值、极对数0、反向区间，检查字段提示与上一组有效结果保留。
4. 检查有刷p/Q禁用与无刷K禁用，切换拓扑后的候选、电频边界和已保存档案值。
5. 图中点击观察转速、DataGrid选择与右侧依据联动；候选、频带、频谱显示切换；同频多候选分别保留。
6. 用examples频谱文件通过真实原生文件对话框读取、预检、导入；坏编码、中间空行、重复频率整批拒绝且可恢复。
7. 真实保存/打开/另存为对话框，中文路径、空格路径、只读目录、取消选择、已有文件覆盖确认、外部修改冲突、备份恢复；检查资源管理器定位。
8. 在不同参数下创建快照、比较、扫查与反算，改参数后旧扫查导出被阻断；按文档解释缺项与拓扑限制。
9. 项目保存重开，搬迁项目到另一目录后核对原始点和来源；选全部成果类型验证文件写入、编码、单位和标记。
10. 未保存退出逐一测试保存、放弃、取消；未完成新增表单与坏草稿不得静默遗漏。
11. 截取真实窗口主要任务图，逐张确认内容与手册步骤一致。将截图插入DOCX，替换“待实机截图”说明。
12. 使用Microsoft Word打开操作说明书，核对实际分页不少于10页；逐页检查文字、图注、页眉页脚、表格跨页与断页，导出PDF并记录实际页数。未完成前材料保持草稿。

记录应写明Windows版本、.NET版本、屏幕DPI、日期、输入、步骤、预期和实际结果，失败项与未测项单列。最大允许数据量性能需另行负载验证，不能从普通示例推断。
