# 空调鼓风机风量挡位与共振避让设计软件 V1.0 设计方案

目标用户为汽车空调系统与NVH工程师。用户在设计风量挡位转速时，需要同时核对旋转阶次、叶片通过频率和壳体/风道模态频率，避免只看一个挡位而遗漏其他交叉。软件建立可保存项目，管理候选阶次、模态和多个挡位方案，显示转速—频率交叉，进行约束内离散扫描、方案对比，并生成现场验证清单。

核心对象为项目、激励阶次、模态、方案、挡位、验证记录及审计事件。数据来源为用户录入或UTF-8 CSV；示例为确定性的模拟设计数据，绝不标成实测。正常启动空白。保存项目内嵌全部输入；格式版本1；服务端原子替换与备份；导入整体验证，错误不改变当前项目。

频率 f=q*n/60；叶片阶次q=叶片数×谐波倍数；精确交叉转速n=60*fn/q。敏感半宽为max(工程绝对半宽, fn*工程百分比, 可选ζ*fn)，其中阻尼项仅是轻阻尼孤立模态的带宽近似，不估算声压或实测响应。考虑挡位转速容差后，只要频率区间与敏感区间相交即列为潜在接近。扫描在给定转速网格与挡位间距约束下，用动态规划最小化接近组合数及转速偏移代价；结果只是设计候选，不保证风量、效率或噪声改善。

界面采用常驻对象树、中央交互图、右侧属性、下方结果核对与验证台账。点击对象和图中挡位直接联动，不使用模块页切换。采用石墨色细框、暖白画布、橙色激励、紫色敏感范围，避免复用旧项目的青绿导航页。

首版实现：项目新建/打开/复制/归档、参数及对象增删、CSV预检、双方案比较、离散扫描、撤销重做、验证清单、审计、保存重开、JSON/CSV/HTML/SVG导出。限制：无波形处理、无声压预测、无有限元、无车辆风量模型、多用户协作和实测设备接口。

生产源码统计：src下.cs、.razor、.css、.js非空手写行；排除obj/bin、依赖、测试、工具、文档、示例。新项目基线0，最低3500行，按完整功能实现核验；每个文件都应参与构建或静态服务。测试以独立数值样例和边界为主，浏览器实际验证输入、联动、扫描、保存重开、导出和窄屏。运行条件为.NET10、现代浏览器；正式Word分页须由Microsoft Word核实，环境无法执行时保留明确未验证项。
