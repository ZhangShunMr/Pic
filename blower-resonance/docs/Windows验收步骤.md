# 目标 Windows 补充验收步骤

环境前提：Windows 10/11 x64，普通用户；自包含目录整体解压。记录OS、屏幕分辨率、缩放比例、程序SHA256与日期。源码验证须.NET 8 SDK。已在Windows Server 2025 runner执行生产窗口与绑定检查、18张原生截图和直接exe启动；证据见screenshots。以下列出完整验收方法，未被自动化覆盖的文件对话框、快捷键及目标高DPI仍需补验。不得把Linux交叉编译或ViewModel测试单独称为桌面验收。

1. 断开网络，双击BlowerResonance.exe。应直接打开WPF窗口，起始无阶次、模态和方案，不打开浏览器；记录进程及窗口真实截图。
2. 使用左侧项目与来源、电机与工程规则编辑并应用；输入叶片0、NaN、转速上限低于下限。应显示字段或完整项目错误，旧数据保持，修复后可应用。
3. 在空白项目新增叶片通过1倍频、600Hz模态（阻尼0.02，声明来源）、一个方案和900rpm挡位。F5；应600Hz、半宽18Hz、敏感转速853～947rpm。原生频率图应显示阶次线、模态带和挡位线；打开全部接近明细核对净距−31.333333Hz。
4. 将挡位947rpm应用并计算，应触边接近；改947.01rpm则不接近。点击方案属性锁定方案，挡位修改应拒绝；解除后可编辑。
5. 运行扫描，查看明细，接纳应建立新方案，原方案保留。比较当前和候选，差值方向为目标减基准。改变规则应使原结果无效，不允许导出过期数据。运行规则敏感性并导出。
6. 生成验证任务，填写负责人、方法、证据及已记录证据状态。改输入后应转为需复核；删除被引用模态应拒绝。检查撤销重做及累计审计。
7. CSV分别检查正确表头、引号逗号、非法数字、未闭合引号、不满足间距及修改后重新预检。任何错误不应整批污染项目。导入挡位建立新方案，导入模态追加。
8. Ctrl+S保存，修改后再保存，检查.bak；关闭重开核对来源、规则、方案、验证。移动项目文件后重开。另一个程序修改同路径后保存应拒绝，另存为可保全工作。
9. 项目库保存、打开；再次保存形成备份后恢复备份为草稿。损坏项目应可见错误。归档禁止编辑，解除归档可继续。
10. 导出CSV、SVG和HTML，核对软件名V2.0、模拟或人工来源、单位、输入哈希、模态独立来源。只报告潜在接近，不含虚构实车改善。
11. 检查Ctrl+N/O/S/Z/Y与F5、键盘遍历、窗口1040×700和1450×940、Windows 100%/150%/200%缩放、长来源、多挡位滚动及空结果。记录真实绑定错误和必要修复，编译成功不替代这些检查。
12. 用tools/capture-windows.ps1捕获真实WPF窗口，逐图核对无遮挡、清晰度、文字与手册引用。将截图加入操作说明书，再用Microsoft Word逐页检查并导出PDF，确认至少10个有效页面。没有Word时不得写成已确认页数。

每项记录“输入／预期／实际／证据路径／通过或失败”，由实际执行者填写；自动执行结果见windows-ui-evidence.json；本文件不替未执行的目标硬件检查预填通过结果。
