# 车身声学泄漏路径与封堵试验分析软件 V1.0

本项目面向车辆声学试验工程师，在同一车辆、测点和工况下组织基线、单项封堵、组合封堵及恢复试验。解决电子表格中条件遗漏、错误配对、分贝统计混用与来源不可追溯问题。软件不从声级差反推路径独立能量贡献，不把单项分贝相加预测组合，不提供声源分离、自动因果诊断或合规认证。

## 工作流与实现方案

用户从空白项目开始，维护封堵位置、条件、试验和频带测量，手动选择每对基线及处理试验，检查比较条件，再计算频带和总声级差、重复性、漂移及恢复结果，保存为内嵌全部测量的 .aslp.json 项目，重新打开并导出 HTML 报告与 CSV 明细。模拟样例通过独立入口载入并持续标记。

本地 Python 3.12 标准库 HTTP 服务仅绑定 127.0.0.1，浏览器使用 HTML、CSS、原生 JavaScript。无需网络 CDN，无第三方生产依赖。Model 为 Python 校验模型及分析服务；ViewModel 为浏览器可观察状态及命令；View 为独立页面渲染函数。服务端无共享项目状态，每次操作处理一个显式项目快照。项目在浏览器工作副本中，显式下载保存，文件导入重新打开。服务器不自动写入用户数据目录。

## 规模口径与最低目标

新项目基线为零。开发开始前确定最低目标：手写生产源码非空行不少于 3500 行。纳入 acoustic/*.py、web/*.js、web/*.css、web/*.html；排除测试、工具脚本、文档、示例、生成材料、截图、依赖及构建产物。以 tools/source_inventory.py 重复统计。代码必须服务实际入口、输入验证、分析、导出和交互，不以行数代替功能验收。

## 对象与规则

项目拥有元数据、版本、封堵位置、测量口径与工况、试验、显式配对、分析参数及操作审计。试验拥有类型、条件引用、封堵位置引用、时间、重复组、来源类别与来源说明、频带声级。基线与恢复没有封堵位置；单项恰有一个，组合至少两个。删除被引用对象时阻止，先处理关联试验或配对。原始数据随项目内嵌，不依赖外部音频和图片。

不同车辆、测点、声源、路面、挡位、转速、车速、温度容差、计权、时间计权、频带制、仪器、标定、采样时长或单位会阻止比较；缺少必要口径也会阻止。允许缺失频带，以空值保留，按共同有效频带比较；不补零。总声级求和只针对用户声明的互不重叠频带，且完整性一致；部分频带单独标记，不冒充全频总声级。漂移和恢复阈值是用户自定工程筛查参数，不是标准限值。

## 验证与交付

独立已知数值、异常输入、版本与损坏文件、导入事务性、保存重开、条件阻断、恢复检查、浏览器端完整流程、报告与截图均记录。软著提供说明书 DOCX、预览 PDF、信息采集表、源码清单和实际截图。缺少申请人模板和登记事实的字段留待确认。Word 实际分页需在 Microsoft Word 中复核，不能用手动分页符或其他引擎的页数代替。
