# 软著信息采集表（草稿）

软件全称：车身声学泄漏路径与封堵试验分析软件

版本号：V3.0（程序3.0.0；项目格式2）

平台：Windows x64；C# / .NET10 / WPF / MVVM；真实入口AcousticSeal.sln。

项目扩展名：.sealproj；成果：.report.html、.results.csv、.measurements.csv、.analysis.json及辅助核对JSON。

软件主要功能（Unicode汉字计数：778）：

本软件用于车身封堵试验频带记录的离线整理、显式配对分析、质量检查及成果归档。软件以项目作为独立工作对象，支持空白建立、文件打开、项目复制、参数修改、归档、保存及重开，项目中内嵌测量频带、来源说明、操作审计和复核快照，便于在不同目录搬迁后核对原始输入。封堵位置管理记录区域、材料、覆盖范围、实施工艺、恢复工艺及附件编号，试验通过唯一标识引用位置，删除仍有引用的对象时会阻止操作并指出关联记录。工况管理记录车辆、测点、激励、场地、挡位、计权、积分定义、频带制、仪器、标定、单位、车速、转速、温度、时长、采样率和同步说明，比较前检查必要口径及工程容差，缺失或不一致时保留阻断原因。试验工作表分别管理基线、单项封堵、组合封堵和解除封堵恢复记录，支持数据来源区分、重复组、带时区时间、频带表格编辑、两列文本粘贴和试验结构复制。批量导入采用明确的试验标识及频率声级三列表格，提供分隔符选择、合并和替换模式、行号错误反馈、覆盖数量预检及整批确认，错误或过期预检不会改变项目。显式配对由用户选择基线、目标和用途，计算基线减目标的测得声级差，显示原始频谱和零基准差值图，并允许按频率范围筛选显示。质量检查包括重复组有效样本、缺失数量和样本标准差，基线漂移及恢复检查采用有效频带的最大绝对差与用户工程阈值比较；重复配对的算术差均值与组能量均值差分别列出，样本不足或试验复用时不生成独立样本均值区间。辅助功能对同一输入比较不同工程参数判读，按对象标识和频率核对项目输入版本，并导出原始频带人工核对表。保存采用文件冲突检查、临时文件替换及覆盖备份，打开备份和旧格式后要求另存。成果输出提供完整报告、结果表格、原始频带交换文件及分析快照，保留来源、单位、参数、版本和输入指纹。界面采用原生窗口、侧边任务索引、对象列表和数据工作表，编辑草稿验证后应用，切换及退出前处理未保存工作，支持会话撤销重做和累计审计。软件不采集音频，不再次加权，不认证标定或实测声明，不把封堵声级差作为路径独立贡献，不相加单项分贝预测组合，工程阈值不是标准限值，模拟案例不能证明实车效果。

技术特点：原生WPF工作表与独立MVVM层，域规则和界面编排分离；显式可比性边界、缺失不补零、稳定能量运算、独立性检查、来源延续、内嵌频带、冲突检查、备份及可追溯成果。
