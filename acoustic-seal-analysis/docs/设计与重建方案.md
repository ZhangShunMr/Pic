# Windows 原生重建方案

目标用户为整理车身封堵试验频带数据的声学工程人员。需要将位置工艺、测量口径、试验来源、显式基准配对、质量判读和成果溯源保存在一个离线项目中。软件不直接采集声音，不分析音频，不以声级变化推断独立路径贡献。

本次范围是替换界面宿主和交付方式的原生重建，不以扩充旧功能规模为目标。旧基线为备份中 src 内手写生产源码（.cs/.razor/.css）7140非空行；目标为原生可运行工作流，生产 .cs/.xaml 非空行至少3500。统计不含测试、文档、生成文件、bin/obj、示例及工具脚本。不是功能扩充项目，因此不把原 Web 宿主行数当作需要倍增的指标；不声称达到旧版两倍代码量。交付清单逐文件可复核，核心层复用明确标识。

核心对象为项目、封堵位置、工况、试验、频带、配对、参数、审计和复核。试验通过 GUID 引用工况和位置，配对明确基线与目标。删除有引用的对象会阻止。普通项目空白，演示入口生成新工作对象，先处理未保存内容。

界面采用声学实验工作台：深青色左侧任务索引、对象列表、频带编辑表、铜色来源提示和右侧检查栏。顶部只有标准文件/编辑/成果菜单。WPF 使用 Menu、ListBox、DataGrid、ScrollViewer、CheckBox、ComboBox 和原生文件对话框；绘图由 DrawingContext 完成。最小窗口1180×720，初始1480×960；实际缩放、长文本及DPI检查待Windows验证。

实现分层：Core 保留域验证、计算、文件编解码和成果输出；DesktopLogic 负责可跨平台测试的草稿、命令、导航、脏状态、文件保存边界；Desktop 负责 WPF 绑定、绘图与本机对话框。窗口后置代码只负责初始化及退出时提交焦点输入，业务计算不进入事件处理器。

保存项目为版本2的.sealproj，软件版本3.0.0。仍支持旧版格式迁移；迁移/备份打开后必须另存。原始频带内嵌，照片/音频/原始文件编号为文字引用，不携带附件。互斥文件锁、SHA-256冲突检查、同目录临时文件和.bak减少覆盖风险；用户仍需按项目制度备份，不能保证所有磁盘故障都不丢失。

资源风险包括Windows运行条件、软著专用模板与申请人事实。当前环境为Linux，具备.NET10 SDK和Windows targeting pack；只能跨编译及运行纯托管核心和MVVM逻辑。Windows桌面、真实截图、Word分页均作为未完成验收项记录，不能据编译成功声称GUI已验证。
