# 车身声学泄漏路径与封堵试验分析软件 V1.0

本地运行的车身声学试验管理与比较软件。采用 MVVM：Python 领域模型及计算服务、JavaScript 可观察 ViewModel、HTML/CSS 视图。默认空白启动，模拟演示需用户主动载入。

## 启动

需要 Python 3.12 或更高版本，以及支持 JavaScript 模块和下载功能的现代浏览器。生产程序仅依赖 Python 标准库，无 npm 安装、无 CDN、无联网计算。

```sh
cd acoustic-seal-analysis
python -m acoustic.server
```

浏览器打开 `http://127.0.0.1:8765`。也可在 Linux/macOS 运行 `./run.sh`，Windows 双击 `run.bat`（需配置 Python）。端口冲突时传入 `--port 8766`。服务器固定监听本机，不提供远程多人访问。

## 完整流程

1. 在“项目工作台”填名称和负责人，应用项目信息。
2. 在“封堵位置”定义位置、材料和工艺；在“工况与口径”记录车辆、测点、声源、路面、挡位、速度、转速、温度、积分时长、计权、频带制、仪器和标定。
3. 在“试验与频带”建立基线、单项、组合、恢复，逐行输入 `Hz,声级dB` 或先建档后导入长表 CSV。来源说明必填。
4. 在“显式配对”分别建立封堵、基线漂移、恢复配对。跨工况、缺必要口径或混合来源的配对会被阻断并保留原因。
5. 在“比较与统计”查看频带差、录入频带合成差、重复配对统计和单项/组合矩阵；在“质量与复核”查看重复性、漂移、恢复、频带覆盖和审计。
6. 下载 `.aslp.json` 项目并确认浏览器实际下载位置；再用“打开项目”重开核对。导出 HTML 报告、结果 CSV、原始频带 CSV。HTML 报告可用浏览器打印为 PDF。

“载入模拟样例”会确认当前工作副本替换，内含 8 个纯模拟试验、6 个配对。`examples/模拟演示.aslp.json` 同样为模拟数列，来源在 `acoustic/demo.py`，不含真实测量。已有仓库图片和音频不参与本软件、未改动。

## 计算边界

结果是封堵前后测得声级差，不是路径独立能量贡献；单项分贝不可相加预测组合。正差表示该配对目标声级更低。频带声级须已完成所声明的计权，软件不读取音频或再次计权。

缺失不补零；每频带仅比较共同有效值。录入频带合成仅在用户确认互不重叠、频带集合相同且全部有效时比较，不冒充全频总声级。等权能量均值、配对差算术均值、组能量均值之差分别命名。n=1 或配对复用试验时不生成置信区间。阈值为用户工程设置，非标准判定。
